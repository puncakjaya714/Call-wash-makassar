# CALL WASH MAKASSAR — GitHub Pages

Website statis siap dipublikasikan menggunakan GitHub Pages.

## Isi repository
- `index.html` — halaman utama website.
- call-wash-logo.jpg` — logo CALL WASH yang dipakai sebagai gambar utama.
- `.nojekyll` — menonaktifkan pemrosesan Jekyll untuk file statis.

## Cara menerbitkan website (GitHub Free)

1. Masuk ke GitHub dan login.
2. Klik tombol **+** di kanan atas, lalu pilih **New repository**.
3. Isi nama repository, misalnya `call-wash-makassar`.
4. Pilih **Public** (untuk GitHub Free), lalu klik **Create repository**.
5. Buka repository yang baru dibuat.
6. Klik **Add file → Upload files**.
7. Unggah semua isi ZIP ini: `index.html`, folder `assets`, dan `.nojekyll`.
   - Pastikan `index.html` berada langsung di root repository, bukan di dalam folder tambahan.
8. Klik **Commit changes**.
9. Buka tab **Settings** pada repository.
10. Pilih **Pages** di bagian **Code and automation**.
11. Pada **Build and deployment**, pilih **Deploy from a branch**.
12. Pada bagian Branch, pilih `main` dan folder `/(root)`, lalu klik **Save**.
13. Tunggu proses build/deploy selesai. Alamat website akan muncul di halaman **Settings → Pages**.

Untuk repository bernama `call-wash-makassar`, alamat umumnya:
`https://USERNAME.github.io/call-wash-makassar/`

Ganti `USERNAME` dengan username GitHub Anda. Jika nama repository berbeda, alamat URL juga akan berbeda.

## Catatan penting
- Website ini sudah berupa HTML/CSS statis sehingga dapat dipublikasikan di GitHub Pages tanpa PHP atau database.
- GitHub Pages pada GitHub Free memerlukan repository publik.
- Website yang dipublikasikan dapat dilihat publik. Jangan unggah data pribadi atau rahasia.
- Hosting GitHub Pages gratis selama mengikuti ketentuan dan batas penggunaan GitHub; nama domain khusus seperti `.com` biasanya memerlukan biaya.
- Instagram ditautkan ke `https://www.instagram.com/call.wsh/`.
- Tombol TikTok saat ini mengarah ke pencarian "CALL WASH MAKASSAR". Ganti tautan tersebut di `index.html` setelah URL profil TikTok resmi tersedia.
- Periksa kembali harga, rincian layanan, area gratis ongkir, dan nomor WhatsApp sebelum publikasi.
